# arrodeio-llm

Try three stages of a hands-on LLM project: a from-scratch char-level GPT, a
fine-tuned Portuguese GPT-2, and a Brazilian-Portuguese instruct model
(Tucano-1b1-Instruct) fine-tuned with LoRA to write *cordel* — the rhyming
folk poetry of the Brazilian Northeast.

v2 (the best one) runs on a shared ZeroGPU — genuinely free, no account
upgrade needed, just a daily time quota per visitor.

Code and full write-up: https://github.com/bsana1/arrodeio-llm
